# SIAP — Sistema Inteligente de Agenda Pessoal

**Sua rotina organizada em um só lugar.**

O SIAP é um projeto de agenda pessoal pensado para ajudar as pessoas a organizar compromissos e acompanhar melhor as atividades do dia a dia. A proposta é reunir a rotina em um ambiente simples, claro e fácil de usar.

## O que o SIAP oferece

- Agenda diária e calendário mensal para visualizar compromissos.
- Cadastro de atividades com data, horário e categoria.
- Opção de adicionar compromissos escrevendo o que precisa ser feito em linguagem natural. O SIAP sugere os detalhes para revisão antes de salvar.
- Acompanhamento de tarefas pendentes e concluídas.
- Exclusão de compromissos pela agenda ou com ajuda do assistente, sempre com confirmação antes de apagar.
- Contas pessoais para manter cada agenda associada ao usuário conectado.
- Página de conta para atualizar nome, foto de perfil, telefone e senha.

No modo visitante, a agenda fica salva no navegador usado. Ao entrar em uma conta, os compromissos são associados àquela conta.

## Objetivo

A ideia do SIAP é tornar mais simples o planejamento dos compromissos e das responsabilidades cotidianas. Com uma visão clara do que precisa ser feito, o usuário pode organizar melhor seu tempo e acompanhar sua rotina com mais tranquilidade.

O projeto foi pensado para crescer gradualmente. Saúde, estudos, finanças, casa, compras e cuidados com o veículo fazem parte da visão de organização ampla do SIAP; por enquanto, esses temas aparecem como categorias da agenda e podem receber recursos próprios no futuro.

## Status do projeto

O SIAP está em desenvolvimento. A agenda, as contas e a organização básica dos compromissos já estão disponíveis; novas melhorias podem ser adicionadas conforme o projeto evolui.
